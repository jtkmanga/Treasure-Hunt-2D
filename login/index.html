สถานะ Firebase

กำลังตรวจการตั้งค่า…

ตั้งค่า Web App สำหรับทดสอบ

กด Copy ที่ Firebase Project settings → Your apps → SDK setup (Config) แล้ววางโค้ด firebaseConfig ด้านล่าง ระบบอ่านเฉพาะข้อมูลเว็บที่จำเป็น โดยไม่รันโค้ดและไม่ส่งข้อมูลไปเซิร์ฟเวอร์

ใช้เฉพาะ Web SDK Config เท่านั้น ห้ามวาง Service Account, Private Key, API Token หรือข้อมูลการชำระเงิน
