ตั้งค่า Web App สำหรับทดสอบ

กด Copy ที่ Firebase Project settings → Your apps → SDK setup (Config) แล้ววางโค้ด firebaseConfig ด้านล่าง ระบบอ่านเฉพาะข้อมูลเว็บที่จำเป็น โดยไม่รันโค้ดและไม่ส่งข้อมูลไปเซิร์ฟเวอร์

App Check (ไม่บังคับในขั้นทดลอง)

หลังจากลงทะเบียน Fraud Defense ใน Firebase แล้ว ให้นำ Site Key แบบสาธารณะ จาก Google Cloud มาวางด้านล่างก่อนกดใช้ Firebase Config ระบบจะไม่บันทึกคีย์ลง GitHub และไม่รีเฟรช Token อัตโนมัติ

ใช้เฉพาะ Web SDK Config เท่านั้น ห้ามวาง Service Account, Private Key, API Token หรือข้อมูลการชำระเงิน

ยังไม่เริ่มทดสอบ App Check

ตรวจบัญชีที่ถูกปิดใช้งานหรือถูกเพิกถอน (Staging)

ยังไม่ตรวจสถานะบัญชีกับ Firebase Backend

ใช้งานได้หลังตั้งค่า Firebase Web API Key ที่ Cloudflare Worker และ Deploy Staging API รุ่นใหม่เท่านั้น ระบบนี้ไม่ได้เปิดคะแนนแข่งขันหรือการชำระเงิน

ปุ่มแรกทดสอบขอ Token บนมือถือ ปุ่มที่สองส่ง Token ไปตรวจลายเซ็นกับ Cloudflare โดยไม่บันทึก Token ลงหน้าเว็บ

ระบบจะขอ Token เฉพาะตอนกดปุ่ม และใช้ Token ที่ยังไม่หมดอายุจากแคชหากมีอยู่ ผลสำเร็จยังไม่หมายความว่า Worker ได้ตรวจ App Check Token แล้ว
